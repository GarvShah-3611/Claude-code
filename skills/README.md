# Downloaded Skills

This directory contains three UI/UX-focused Claude Code skills/plugins, downloaded as requested:

1. **`ui-ux-pro-max-skill/`** — from [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
2. **`impeccable/`** — from [pbakaus/impeccable](https://github.com/pbakaus/impeccable)
3. **`frontend-design/`** — the official `frontend-design` plugin from Anthropic's [claude-plugins-official](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/frontend-design) marketplace (also listed at [claude.com/plugins/frontend-design](https://claude.com/plugins/frontend-design))

Each subdirectory is the unmodified content of its source repository (or plugin path), with `.git` metadata stripped. See each subdirectory's own README/SKILL files for usage instructions.
